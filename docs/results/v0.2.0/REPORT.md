# 路线 A：P0 基线复现与问题诊断（v0.2.0）

日期：2026-11-07。范围：GEFCom2014 的 10 场、GEFCom2012 的 7 场；seed=0。全部日期均为已查看过的历史开发/回顾性评价，不能当作全新测试集。本版本没有提出或验证新的预测模型。

## 核心结论

复现检查未发现执行或实现偏差；QRF 相对持续性具有预测能力，但本轮没有检验训练配置是否充分优化，也不能分离训练、模型和 NWP 的贡献。已证实的问题包括数据可用性不足、总体校准掩盖条件误差，以及逐置信水平独立校准破坏区间嵌套。尚不能从这次实验因果区分“训练样本不足”“模型表达不足”和“NWP 信息不足”的贡献。

优先保留冻结 QRF，下一阶段分别检查上/下尾与零功率质量点，并控制区间宽度；暂不因总体覆盖达标就升级为新方法。

## 复现与协议

- 全部 17 场从原始 CSV 重建样本、标签、历史功率、可用性、时间索引和特征，与副本缓存一致；重新拟合的训练期中位数填补及缺失指示器也一致。
- 全部冻结模型 q05/q95 与历史缓存最大绝对差：0.0；90% rolling84 CQR 在验证/评价期均逐元素一致。
- 从头重训只在预先指定的两套数据 1 号风场进行：两次均为 500 棵树、leaf=10、seed=0；树结构及七个分位数预测与冻结模型完全一致。不是 17 场重训，也不是多随机种子实验。
- 历史窗口 24h、预测 1–24h、每日一次发报、功率按原数据容量归一到 [0,1]。QRF 使用相同 NWP/历史输入，保留完整叶响应。
- 2014：2012 年训练，2013 年 1–3 月初始校准，4–6 月验证，7–12 月回顾性评价。2012：2009 年 7 月至 2010 年末训练，2011 年 1–3 月初始校准，4–6 月验证，2011-07-01 至 2012-06-27 发报日期评价。
- 评价期的初始校准标签来自验证期；滚动校准只追加已经完整到达的有效日标签，要求 target_end <= origin；同日真实标签不会参与当次校准。假设零观测上报延迟。
- CQR 对各提前量分别使用 signed max(qlo-y,y-qhi) 分数和有限样本阶统计量；允许负修正，交叉时按历史规则收拢到原始区间中点，再裁到 [0,1]。静态 CQR 固定初始校准集；rolling84 使用最近 84 个日历日。
- GEFCom2014 的天气发报可用性采用竞赛数据推定，缺少完整原生气象发布时间证据；因此这是基准协议复现，不能宣称已验证实际业务的实时可用性。2012 使用不晚于发报时刻的原生 00/12 批次，允许年龄 0/12/24h。

## 条件误差：总体达标仍有局部失败

| 数据 | 90% rolling84 分组 | 覆盖率 | 下尾漏率 | 上尾漏率 |
|---|---|---:|---:|---:|
| 2014 | all | 91.58% | 4.00% | 4.42% |
| 2014 | up_ramp | 89.16% | 1.30% | 9.54% |
| 2014 | down_ramp | 91.23% | 6.89% | 1.89% |
| 2014 | near_zero | 83.10% | 16.90% | 0.00% |
| 2012 | all | 91.92% | 1.78% | 6.29% |
| 2012 | up_ramp | 81.95% | 0.55% | 17.50% |
| 2012 | down_ramp | 92.64% | 3.44% | 3.92% |
| 2012 | near_zero | 95.22% | 4.78% | 0.00% |

爬坡定义为相邻小时变化超过容量的 0.1；h1 与最后历史观测比较。近零定义为真实功率 <=0.01。分组按事后真实标签建立，只用于诊断，不能据此在部署时选择模型。表中每组的逐场小时数/涉及日期数见 metrics_per_farm.csv；涉及日期不是独立事件数。

- 2012 上爬坡仍主要漏上尾。滚动校准把覆盖从 raw 的约 78% 提升到约 82%，但并未解决这类条件误差。上爬坡 IS 的上尾惩罚见 interval_decomposition.csv。
- 2014 近零覆盖从 raw 的约 86% 降到 rolling84 的约 83%。signed CQR 可以在总体上需要收缩的提前量/日期抬高下界；这对近零子组可能不利，并非所有校准都会提高所有子组覆盖。

  - 2014 近零小时中，raw 已覆盖而 rolling84 丢失 209 个，raw 未覆盖而 rolling84 新覆盖 106 个；前者中负修正涉及 209 个。这里是汇总小时数；不等同于宏覆盖率差的分母。
  - 2012 近零小时中，raw 已覆盖而 rolling84 丢失 21 个，raw 未覆盖而 rolling84 新覆盖 155 个；前者中负修正涉及 21 个。这里是汇总小时数；不等同于宏覆盖率差的分母。

## 不确定性与可支持的比较

评价期对所有场同步抽取完整日历的循环移动 14 天块，1000 次，seed=20261107；无服务日期保留为零计数。区间条件于已拟合模型，不包括模型重训随机性；未做多重比较校正，不应把分组筛查当确认性检验。

| 数据 | 比较（后者减前者） | IS 差 | 95% 块区间 |
|---|---|---:|---|
| 2014 | QRF_raw → rolling84 | -0.000165 | [-0.002052, 0.001660] |
| 2014 | QRF_CQR_static → rolling84 | -0.000384 | [-0.002109, 0.001103] |
| 2012 | QRF_raw → rolling84 | -0.016372 | [-0.024155, -0.009315] |
| 2012 | QRF_CQR_static → rolling84 | -0.009165 | [-0.013662, -0.004973] |

2012 的 IS 改善在这组回顾性块分析中较清晰；2014 的区间跨零，不能声称滚动校准改善了 IS。2012 rolling84 比 raw 更宽，因此也不能称作“同时变窄且更准”。

初始 runner 的 paired_blocks.csv 按可发报日期索引抽块，2012 缺失日期会被压缩；该文件仅保留本地过程记录，不用于结论或发布。发现日期缺口后、分析性能前已澄清为完整日历抽样；正式结果使用 [paired_calendar_blocks.csv](paired_calendar_blocks.csv)，详见 [协议澄清](calendar_bootstrap_protocol.json)。没有改变模型预测或校准端点。

## 方法的具体局限

1. **边际覆盖与条件覆盖不同。** 逐时距 CQR 已经分别校准 h1–h24，不能把“首次按提前量校准”当作下一步创新。时间依赖和季节漂移下，本实验不提供无条件的有限样本覆盖保证。
2. **本次校准的宽度代价。** 90% raw 宏宽度约占 rolling84 宏宽度的 93%–97%。本次测试的静态/滚动 CQR 没有实现收窄；其他校准方案能否在同样覆盖目标下收窄，仍需配对比较。该宽度比例不是其他校准方法的性能下界。
3. **独立置信水平校准不保持嵌套。** raw 分位数无交叉，但 CQR 各水平的独立修正会导致 80% 区间不完全包含于 90%、或 90% 不包含于 95%。未静默排序修复；统计见 scores_per_farm.csv。WIS 仍按各区间独立计分，不能把这些端点冒充一个已校准完整 CDF。

   - 2014：80/90 嵌套违反 516/42432 小时，90/95 嵌套违反 1230/42432 小时；两类可能重叠。
   - 2012：80/90 嵌套违反 592/52416 小时，90/95 嵌套违反 669/52416 小时；两类可能重叠。

4. **24h 轨迹覆盖没有保证。** 90% rolling84 的整日全 24 点同时覆盖只有约 38%（2014）/45%（2012）；这不是边际 90% 方法出错的证明，而是联合覆盖与逐点覆盖的目标不同。
5. **数据质量与机制无法混为一谈。** 可用性缺失已被实证识别；缺少限电/故障标志，不能把所有近零点当异常删掉。训练/评价功率分布有差异，风速落在训练 1%–99% 范围之外约占 2%–3%，但单变量范围无法证明全部高维工况已经充分覆盖，更不能证明分布漂移是唯一原因。

## 下一步可执行方案（本版本未执行）

1. **P1 首选：固定 QRF 的完整分布校准。** 借鉴计划中的 SCDRF/共形预测系统，保留离散零质量和分位数核语义；与当前 84 天 CQR 在同样标签到达规则下比较。先解决跨置信水平一致性，再评估覆盖、宽度与 proper score。
2. **低成本对照：上下尾分别校准。** 相同总失覆盖预算，分别处理上爬坡上尾和近零下尾；按提前量或已知输入进行小样本收缩，禁止按未来真实爬坡/近零标签选输出。原项目历史中已探索过独立尾校准，因此只能称复现/借鉴对照，不预设它会胜出。
3. **近零问题的后备：零质量点＋正功率分布两部分建模。** 只用发报时可用的历史/NWP 估计近零概率，再建模正功率分布；与相同输入的 QRF 比较，关注漏下尾、宽度和 WIS 的共同变化。不能依赖不可获得的限电标签。
4. **单列数据可用性路线。** 缺 NWP 的周四可以研究历史功率 fallback 或严格因果天气补缺；必须在扩展服务范围上同时报告覆盖与服务率，不能拿原来易预测子集的指标冒充全日历效果。当前 P0 不填补这些 NWP。
5. **P2 时序模型推迟到 P1 比较明确之后。** 小 TCN/GRU 可以检验显式时序表示是否有益，但现有证据不足以断言换深度模型就会改善。
