# 路线A技术方案（v0.1.0）

执行状态更新（2026-11-07，发布版本 v0.2.0）：P0 已完成；P1–P4 未执行。[P0 报告](results/v0.2.0/REPORT.md) 给出复现证据、失败分组与下一步对照。路线本身仍沿用本方案，不把 P0 诊断当成新算法效果。

日期：2026-11-07。目标：借鉴成熟概率预测方法，优先实现可靠效果；不强求结构创新。该版本是执行计划，不是新实验结果。

## 与另一条路线的边界

原项目由另一会话继续改进。本路线只修改独立副本，不覆盖原代码、模型、结果或默认方案。两条路线最后在同一冻结数据契约和评价口径下比较，不把一条路线的测试反馈继续用于另一条路线选型后仍称独立确认。

## 现状判断

- QRF已学习到明显规律；普通重训和局部上界修正没有稳定解决爬坡问题。
- 早期事件分支有效样本少、门控限制强；年度扩样仍未稳定改善，说明样本量不是唯一瓶颈。
- 局部NWP轨迹在场内开发有信息增益，但跨场零样本迁移未稳定确认；概率校准与排序能力须分开评价。
- 总体90%覆盖不意味着每个事后爬坡组或24h整段轨迹90%覆盖；CQR不能凭空创造气象信息。
- 当前许多日期已被反复查看；新方法的确认必须另留未用于选型的时间或场站。

## P0：锁定数据与复现基线

固定历史24h、预报1–24h、同一NWP信息集、容量归一、时效与发布时间规则、缺失处理和评价样本。读取本地已复制的冻结QRF结果，逐元素复现原始分位与CQR端点。记录输入、配置、代码和模型散列。此阶段不修改原森林、不降低门槛来制造获胜。

## P1：QRF完整分布＋分布级校准（首选）

借鉴Jonkers等Applied Energy 2024的SCDRF/Conformal Predictive System，先复现其核心算法，再与原rolling84 CQR比较。

1. 复用原QRF完整叶响应，生成CDF或所需分位函数。
2. 用模型未拟合过且当时已到达的标签构造分布校准。
3. 同时评估80/90/95%区间、多分位pinball/WIS，以及CDF定义匹配的CRPS。
4. 小幅改进仅做时距分组向全局收缩；不足样本回退，不按未来真实爬坡标签选择输出。

QRF含离散质量，经验CDF和加权线性插值分位核的区别必须保留；不直接套连续PIT公式，不声称任意漂移下有限样本条件覆盖。

来源：https://doi.org/10.1016/j.apenergy.2024.122900

## P2：显式时间结构＋非交叉多分位功率预测

先做小型TCN或GRU：历史功率编码＋发报时已知的未来NWP轨迹编码→24小时多分位输出。先匹配QRF输入，之后再单独比较更长历史。采用单调多分位头和标准pinball训练；不先叠爬坡分类、上界保护与扩散。

比较QRF、相同信息的普通MLP、小型时序模型的原始分布得分，再用相同校准层比较。多时距分位输出仍是边际预测，不冒充联合场景；不强制时间平滑来压掉真实爬坡。

借鉴：非交叉分位网络https://doi.org/10.1109/TPWRS.2022.3202236；样条分位函数https://doi.org/10.1109/TSTE.2022.3175916。条件正规化流作为后备基线：https://doi.org/10.1109/TSTE.2022.3191330

## P3：目标场适应（独立因子）

统一提供相同长度的目标场历史，比较只重校准、只拟合轻量输出、目标场独立模型以及源/目标分布混合。单调概率重标定通常不改变同一场内排序，不能承诺提升同误报召回。所有方法享有相同目标场适应预算，适应/开发/校准/确认按时间隔离。

## P4：有真实集合NWP后再做两源建模

分别处理天气集合与天气到功率条件分布，保留其依赖。不同初始化批次不等同真正天气集合，不通过人为噪声宣称取得真实天气不确定性。先审计数据来源、发布可用性、高度和分辨率。

来源：Dantas/Browell，Wind Energy，https://doi.org/10.1002/we.70079

## 冻结评价与停止条件

- 原始模型：多分位pinball/WIS，CDF语义一致时的CRPS，点MAE。
- 校准后：总体与近零/上爬坡/下爬坡、逐时距覆盖和宽度，区间得分；事件数和服务率同时报告。
- 报警模型：冻结阈值操作结果与事后同误报排序诊断分开，不以降低误报掩盖召回下降。
- 同步时间块配对区间；筛查阶段小预算，入围后再预定多种子和未用于选型的数据。
- 仅靠加宽达标、仅改善已看测试集、或仅改变信息预算时，不升级方法。
- 每个阶段先回答一个问题；P1无收益不自动解释为P2也无收益，P2无收益不回头无限调P1。
